# WZRD.VID v0.3.0

> Historical binary distribution withdrawn. The source tag and release record remain available for historical reference. Previously granted licenses remain unaffected.

ANSI broadcast lab // lo-fi fragment synthesis // public-access hallucinations

## Highlights

- Authentic DATAMOSHING through controlled MPEG-4 Part 2 I/P-frame prediction manipulation.
- Five new Style Stack effects: Pixel Sorting, Databending, Circuit Bending, Hex Editing, and Random Noise B/W.
- `Style begins at` for keeping the opening portion clean before WZRD treatment starts.
- Desktop `.3gp` and `.3g2` import, preview, render, and selected source-audio support.
- Improved HEIC/HEIF handling for protected Messages/Photos paths, including readable-source internalization and clearer rejection guidance when macOS denies access.
- Faster Glitch Hell/ASCII rendering through cached glyph masks, with more detailed renderer timing diagnostics.
- Default-on source-video audio for WZRD.VID Lite and Apple Lite, including random visual cuts and mixing with Add Audio.
- A conventional drag-to-Applications DMG installer, plus a ZIP fallback.

## macOS Install

1. Download `WZRD.VID-macOS.dmg` from the v0.3.0 GitHub Release.
2. Open the DMG.
3. Drag `WZRD.VID.app` onto `Applications`.
4. Choose **Replace** when updating an existing installation.
5. If macOS blocks the first launch, right-click `WZRD.VID.app` and choose **Open**.

The macOS package remains ad-hoc signed and unnotarized. The DMG is an install convenience, not an automatic updater or Gatekeeper bypass.

## Also Available

- `WZRD.VID-macOS.zip` is provided as a fallback packaged-app download.

## Notes

- The packaged Mac app is tested primarily on Apple Silicon. Intel Mac users should run from source for now.
- Replacing the app bundle leaves `settings.json`, `ImportedMedia`, `StillCache`, `Previews`, and user-saved recipe files outside the bundle and intact.
- WZRD.VID processes selected media locally. WZRD.VID Lite also keeps selected media in the browser/device workflow without uploading it.
