# WZRD.VID v0.4.0

//wzrdVID

ANSI broadcast lab // lo-fi fragment synthesis // public-access hallucinations

## Highlights

- More organic, source-responsive Pixel Sorting, Databending, Circuit Bending, Hex Editing, and Random Noise B/W with deterministic corruption, lulls, clusters, and recovery.
- Five clearly grouped DATAMOSH MODES: transition-aware **DATAMOSHING**, recursive **spILL!**, reverse-prediction **SKRRT**, spatial-fragment **ShShSHa**, and transition-flow **FLOWs**.
- A persistent **Layer** control for changing codec-operation order while retaining a single controlled encode and safe H.264/yuv420p output transcode.
- Independent **Style FX Coverage** for full, random-clean, manual-clean, or combined effect sections without changing ANSI Coverage.
- Up to three static output-space **Zones**, with six eligible assignment rows: the five Material Dynamics effects plus SKRRT.
- Hard rectangle containment for the five frame effects and authentic bounded spatial prediction for Zone-assigned SKRRT. ShShSHa and all other codec modes remain deliberately Zone-ineligible.
- Schema-6 settings/recipe persistence with safe schema-3/4/5 migration, malformed-state repair, and compatible historical Layer defaults.
- Reliability fixes for codec auxiliary structure, fragment timing, protected clean intervals, and fail-closed cleanup.

## macOS Install

Install v0.4.0 from the published GitHub Release:

1. Download `WZRD.VID-macOS.dmg` from the v0.4.0 GitHub Release.
2. Open the DMG.
3. Drag `WZRD.VID.app` onto `Applications`.
4. Choose **Replace** when updating an existing installation.
5. If macOS blocks the first launch, right-click `WZRD.VID.app` and choose **Open**.

The macOS package remains ad-hoc signed and unnotarized. The DMG is an install convenience, not an automatic updater or Gatekeeper bypass.

## Also Available

- `WZRD.VID-macOS.zip` is provided as a fallback packaged-app download.

## Notes

- The packaged Mac app is tested primarily on Apple Silicon. Intel Mac users should run from source for now.
- Replacing the app bundle leaves `settings.json`, `ImportedMedia`, `StillCache`, `Previews`, and user-saved recipe files outside the bundle and intact.
- WZRD.VID processes selected media locally. No desktop v0.4.0 feature changes the independent Lite/Apple Lite privacy or release identity.
