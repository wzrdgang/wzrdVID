//// QUICK SUPPORT

Local media in, rendered video out.

WZRD.VID imports user-selected video, still images, and audio, lets you preview and shape visual effects, and exports rendered media to a destination you choose.

LOCAL PROCESSINGNO SIGN-INUSER-SELECTED FILES
IMPORT

Add media

Use Add Media or Add Photos to select supported local files. WZRD.VID copies selected Store inputs into its app container for processing and leaves your source files unchanged.

  • video and still images
  • optional source or external audio
  • HEIC/HEIF where supported
PREVIEW

Build a look

Arrange sources on the timeline, choose a style and effects, then use Preview Selected to inspect the result. You can use Loop, Random, Zones, DATAMOSH, SCATTER, and the available Material controls as the source permits.

EXPORT

Save output

Choose an output destination through the macOS save workflow and render. The Mac App Store build stages work inside its app container, then copies the finished file to the destination you selected.

You keep control of the exported file after WZRD.VID finishes.

CHECKS

If a file does not open or export

Confirm that the file still exists, select it again through WZRD.VID, and choose a writable output destination. For a support request, include your macOS version, WZRD.VID version, the media format, what you expected, and what happened.

CONTACT

Still need help?

Email contact@wzrdgang.com. WZRD.VID is developed and published by AMPYX LLC.

Do not send private media unless it is necessary to diagnose the issue.
