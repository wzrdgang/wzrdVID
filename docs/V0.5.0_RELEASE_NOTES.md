# WZRD.VID v0.5.0

> Historical binary distribution withdrawn. The source tag and release record remain available for historical reference. Previously granted licenses remain unaffected.

//wzrdVID

ANSI broadcast lab // lo-fi fragment synthesis // public-access hallucinations

## Highlights

- Desktop Preview now uses the canonical full-output plan for Random source selection, transitions, delayed audio, ending and Loop behavior, audio fades, and Stutter timing.
- Up to three desktop Zones can use deterministic **Drift** or **Pulse** motion for Pixel Sorting, Databending, Circuit Bending, Hex Editing, and Random Noise B/W.
- Moving Zones follow absolute full-output time, close exactly at the Loop boundary, stay hard-contained, and keep Circuit history bounded by stable Zone ID.
- Preview slices resolve the same moving Zone geometry as their matching full-output interval. **SKRRT deliberately keeps each Zone's saved static base rectangle.**
- Download Update and rendered Preview now report external-open failures instead of silently doing nothing; fresh profiles show the correct 5-second Preview label, and manual Preview cleanup clears stale Open Preview state.
- Schema remains 6. Existing v0.4.0 settings and recipes continue to load; absent motion fields preserve Static Zone behavior.

The separately developed browser/Apple Lite Effect Strength, ANSI Text Density, Reroll Chaos, and empty-recorder protections are not part of the desktop v0.5.0 release scope.

## macOS Install

When v0.5.0 is published in the separately authorized release phase:

1. Download `WZRD.VID-macOS.dmg` from the v0.5.0 GitHub Release.
2. Open the DMG.
3. Drag `WZRD.VID.app` onto `Applications`.
4. Choose **Replace** when updating an existing installation.
5. If macOS blocks the first launch, right-click `WZRD.VID.app` and choose **Open**.

The macOS package remains ad-hoc signed and unnotarized. The DMG is an install convenience, not an automatic updater or Gatekeeper bypass.

## Also Available

- `WZRD.VID-macOS.zip` is prepared as a fallback packaged-app download.

## Notes

- The packaged Mac app is tested primarily on Apple Silicon. Intel Mac users should run from source for now.
- Replacing the app bundle leaves `settings.json`, `ImportedMedia`, `StillCache`, `Previews`, and user-saved recipe files outside the bundle and intact.
- WZRD.VID processes selected media locally. Desktop v0.5.0 does not change the independent Lite/Apple Lite privacy model, production signing, Bundle ID, Team ID, or App Store identity.
- Publication, tagging, uploads, public download-guide changes, and site cutover are deferred to the separately authorized Phase 20R.
