//// QUICK SUPPORT

Pick local media. Make a short chaos cut.

WZRD.VID Lite lets you select your own videos, images, and optional audio, apply compact experimental controls, render a 15, 30, or 60 second clip, and save it to Photos.

LOCAL PROCESSINGNO SIGN-INNO UPLOADS
INPUT

Add media and audio

Tap Add Media to choose local videos, photos, or GIFs. Tap Add Audio to add a separate local audio file. Photos and file access are requested only when you choose these actions.

  • your selected local files
  • optional source and added audio
  • no account or cloud setup
STYLE

Shape the clip

Choose one of five presets, set Effect Strength and ANSI Coverage or Density, then use Random clip assembly and Reroll Chaos when you want a different cut plan.

EXPORT

Render and save

Choose 15, 30, or 60 seconds and Fast 480p or Better 720p, then tap Render. When the clip is ready, tap Download to validate it and save it to Photos.

You control whether the saved output is kept, deleted, or shared after it leaves WZRD.VID Lite.

CHECKS

If media does not open or save

Confirm the file is still available, select it again, and allow the Photos or file access needed for the action you chose. For a support request, include your iOS or iPadOS version, device model, media format, and what happened.

CONTACT

Still need help?

Email contact@wzrdgang.com. WZRD.VID Lite is developed and published by AMPYX LLC.

Do not send private media unless it is necessary to diagnose the issue.
