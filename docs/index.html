WZRD.VID v0.6.0 control board

The approved Mac App Store build combines local media assembly, spatial treatments, codec art, and finished H.264 output.

STYLE + MATERIAL

Combine ANSI/text, chunky blocks, and PUBLIC ACCESS treatment with source-responsive corruption.

  • Pixel Sorting // Databending // Circuit Bending // Hex Editing // Random Noise B/W
  • Effect Intensity // deterministic Weirdness rerolls
  • Style begins at // ANSI Coverage // Style FX Coverage

CODEC ART

Five genuinely different compression and prediction-art behaviors can be enabled together.

  • DATAMOSHING // spILL! // SKRRT // ShShSHa // FLOWs
  • Persistent Layer ordering lets you change which codec behavior runs first, next, and last.

SPATIAL + TIMELINE

Build video/photo timelines, mix source and external audio, and Preview the matching 5/10-second full-output slice with Random chronology, transitions, audio, endings, and Loop timing aligned.

  • Up to three named Zones can use Static, Drift, or Pulse motion with Amount and Cycles; only the five Material effects move.
  • SKRRT keeps each Zone's saved static rectangle; other codec modes remain Full Frame.
  • Broad local media import // source + external audio // H.264/yuv420p MP4 + AAC where audio exists
